Catatan penggunaan

Versi ini berjalan offline setelah file dibuka, tanpa akun atau server. Data hanya tersimpan di browser pada perangkat yang sama. Jangan gunakan file yang sama di banyak HP dengan harapan stok tersinkron otomatis. Untuk penggunaan multiuser perlu backend, autentikasi, dan database terpusat.
